Les 3 endroits à connaître

01

L'app principale (interface joueur)

Landing → tes deux pages Google → l'app de paris. C'est ce que voit un utilisateur normal.

smartphone Sur ton téléphone : tape cette URL dans le navigateur, même Wi-Fi que le PC.
02

L'espace admin

Même URL que l'app. L'onglet Admin apparaît en bas seulement si tu te connectes avec un email admin. Il contient les comptes, les paris à régler, et les Outils backend (verify-account, IMAP, configs OAuth).

Se connecter avec : neyvo.entreprise@gmail.com
bolt N'importe quel mot de passe fonctionne — c'est ton Supabase qui vérifie. La 1re fois, le compte se crée.
03

L'espace partenaire (affilié)

Espace totalement séparé — pas de paris, pas de profil joueur. Le compte partenaire ne voit que sa vue de gestion. L'accès demande deux facteurs : le lien spécial + l'email partner.

http://192.168.1.110:5500/index.html?partner=cademo-partner-2026 open_in_newOuvrir
Se connecter avec : partner@cademo.app
lock Sans le ?partner=… dans l'URL, le compte partner se comporte comme un joueur normal. C'est voulu.

Ce que tu tapes dans les terminaux

Un terminal PowerShell = une chose. Tu peux en avoir 3 ouverts en même temps. Placé dans C:\Users\Leo\cademo\api.

T1
npm start
Lance l'API backend. Reste ouvert.
Ne pas fermer
T2
python -m http.server 5500 --bind 0.0.0.0
Sert l'app web. Reste ouvert.
Ne pas fermer
T3
npm run imap · npm run config -- list · etc.
Commandes ponctuelles. Se ferme après.
Ponctuel

errorTon erreur « npm run imap : Command failed »

Le module IMAP échoue parce que le fichier .env ne contient pas encore ton adresse et ton mot de passe email. Ouvre C:\Users\Leo\cademo\api\.env dans Notepad et remplis :

IMAP_USER=ton.adresse@gmail.com
IMAP_PASSWORD=xxxxxxxxxxxxxxxx

Le mot de passe n'est pas ton vrai mot de passe Gmail. Il faut un App Password (16 caractères, sans espaces) : Compte Google → Sécurité → Mots de passe des applications. Sans ces deux lignes, le module ne peut pas se connecter et affiche « Command failed » — désormais avec un message d'erreur clair qui te dit exactement quoi remplir.
